# SoapyRemote-server-installer

Automated installer for SoapyRemote — remote SDR server support for SoapySDR.

## Features

- Installs SoapyRemote from source
- Configures systemd service for auto-start
- Supports Debian, Ubuntu, Fedora, and RedHat
- Compatible with RTL-SDR, Airspy, HackRF, LimeSDR, and more

## Installation

```bash
git clone https://github.com/hmol33/SoapyRemote-server-installer.git
cd SoapyRemote-server-installer
chmod +x install.sh
sudo ./install.sh
```

## Usage

After installation, connect remotely using SoapySDR with the remote server address.
